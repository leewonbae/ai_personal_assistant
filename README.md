# 비서

Python 가상환경을 만든 뒤 의존성을 설치하고 Streamlit 앱을 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python run.py
```

현재는 개발 편의를 위해 로그인 없이 메인 화면이 열립니다. 로컬 컴퓨터에서만 접속하도록 설정되어 있으며, 인증을 다시 켜려면 실행 전에 PowerShell에서 `$env:APP_REQUIRE_LOGIN = '1'`을 설정하세요. 인증이 꺼진 상태로 외부에 공개하지 마세요. 계정은 `accounts.db`에 보관되며 비밀번호 해시가 포함됩니다.

**오늘 뉴스 확인**에서 한국경제, 경향신문, 뉴시스 금융과 한국은행 경제통계 RSS를 탭별로 조회하고 **지금 새로고침**으로 즉시 수집을 요청할 수 있습니다. 한국경제 기사는 RSS의 최신 20건 중 기사 페이지의 구조화 데이터에서 무료로 명시된 기사만 최대 10건 표시합니다. 유료 기사나 무료 여부를 확인할 수 없는 기사는 제외되므로 표시 건수가 줄어들 수 있습니다. 다른 출처에는 동일한 유료 여부 검증을 적용하지 않습니다.

`python run.py`로 실행하면 브라우저 접속을 기다리지 않고 수집을 시작합니다. 자동 또는 수동 수집이 끝난 시점부터 10분 후 다음 자동 수집이 시작되므로 수동 새로고침 시 대기 시간이 초기화됩니다. 최신 기사 화면은 메모리 결과를 사용합니다. 수집에 실패하면 이전 성공 결과와 시간을 유지하고 경고를 표시합니다. 서버 중지 중에는 수집하지 않습니다. `streamlit run app.py`로 직접 실행할 경우 첫 접속부터 수집이 시작됩니다. 한국경제·경향신문·뉴시스는 확인 가능한 대표 이미지를 표시하며, 이미지가 없거나 접근할 수 없으면 제목만 표시합니다.

날짜별 키워드는 `news.db`에 저장되며 한국 시간 수집일을 기준으로 합니다. 같은 날 같은 언론사 기사 링크는 한 번만 집계합니다. Kiwi 형태소 분석으로 명사와 영문 약어를 추출하고 날짜와 일반 기사 표현을 제외합니다. 의미를 완벽하게 판단하는 방식은 아니며 추출 결과는 분석기와 제외어 목록에 영향을 받습니다.

이 앱의 로그인은 로컬 사용을 위한 기본 기능입니다. 인터넷에 공개하기 전에는 HTTPS, 배포 환경의 접근 제어와 세션 보호 등 추가 보안 검토가 필요합니다. Streamlit 세션은 브라우저 연결이 끊기거나 새로고침될 때 초기화될 수 있습니다.

기존 API는 별도로 `python -m uvicorn main:app`으로 실행할 수 있습니다.
